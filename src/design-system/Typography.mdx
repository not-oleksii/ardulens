# Typography

Exo 2 for interface text at every weight; PT Mono wherever digits need to line up — telemetry
readouts, table numbers, timestamps, param values. Both are self-hosted via `@fontsource` (fully
offline, no CDN) and now apply app-wide — previously PT Mono/Exo 2 were scoped only to the live
ArduPilot Setup pages via a `.ardupilot-setup-theme` class; that scoping has been removed.

## PT Mono — anywhere digits line up

<div style={{ border: "1px solid var(--border)", borderRadius: "var(--radius-lg)", background: "var(--card)", padding: "20px 24px", display: "flex", gap: 40, flexWrap: "wrap" }}>
  {[["Altitude", "142.7", "m"], ["Groundspeed", "18.3", "m/s"], ["Battery", "15.98", "V"], ["Heading", "204", "°"]].map(([label, value, unit]) => (
    <div key={label}>
      <div style={{ fontSize: 11, color: "var(--muted-foreground)", textTransform: "uppercase", letterSpacing: "0.06em", marginBottom: 4 }}>{label}</div>
      <div style={{ fontFamily: "var(--font-mono)", fontSize: 26, fontVariantNumeric: "tabular-nums" }}>{value}<span style={{ fontSize: 13, color: "var(--muted-foreground)", marginLeft: 3, fontFamily: "var(--font-sans)" }}>{unit}</span></div>
    </div>
  ))}
</div>

Use `font-variant-numeric: tabular-nums` (or the `tabular-nums` Tailwind utility) alongside PT
Mono wherever numbers stack in a column, so digits align vertically even as values change.
