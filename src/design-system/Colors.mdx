# Color

Swatches below read the **real** CSS variables from `src/index.css` live (use the theme toggle in
the toolbar above to compare light/dark) — this page can't drift out of sync with the app, since
it's the same stylesheet.

## Status — new, semantic, reserved for state

Never reused as a general accent color — see [Foundations/Naming
convention](/?path=/docs/foundations-naming-convention--docs) for why these are
`--ardulens-status-*` and not `--status-*`.
