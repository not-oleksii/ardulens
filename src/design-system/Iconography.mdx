# Iconography

ArduLens uses exactly one icon library, [lucide-react](https://lucide.dev) — every icon in the
app is **outline/stroke-based** by construction (lucide ships one style, not filled/duotone
variants), so "use outlined icons" is a property of the library choice itself, not a per-icon
decision. Default stroke width is `2`; severity icons in [Alert](/?path=/docs/components-alert--docs)
use the library default, nothing overridden.

## Severity icons pair with a shape, not just a color

An icon's **shape** carries meaning independent of color, so severity is never color-alone:

- **Destructive** → `OctagonAlert` (a "stop sign" silhouette)
- **Warning** → `TriangleAlert`
- **Good** → `CheckCircle2`
- **Info** → `Info`

This mirrors [Badge](/?path=/docs/components-badge--docs)'s own dot-based status pills, which use
the same four-tone system — see [Foundations/Color](/?path=/docs/foundations-color--docs).

## Sizing convention

- `size-4` (16px) inside buttons and alerts (matches text line-height)
- `size-3.5` (14px) inside compact controls (Checkbox indicator, Select item indicator)
- Never resized via `strokeWidth` — a thinner/thicker stroke at the same pixel size reads as a
  different icon set entirely, so every icon in the app keeps lucide's default `2`.
