# Motion

Three durations, one easing curve — reserved for interface **chrome**: reveals, hovers, section
transitions, overlay enter/exit. Never applied to live telemetry numbers or safety-critical
controls (arm/disarm, motor/servo/relay override, calibration), which stay instant by design. All
motion respects `prefers-reduced-motion` (enforced globally in `src/index.css`).

Easing: `cubic-bezier(0.16, 1, 0.3, 1)` (ease-out-expo) — fast start, gentle settle. Applied via
`--ardulens-ease-out`.

## Keyframes

Hand-rolled in `src/index.css` (no animation dependency), applied via Tailwind v4's arbitrary
`animate-[name_duration_easing]` syntax keyed to Radix's `data-state` attribute:

```css
@keyframes ardulens-zoom-in {
  from { opacity: 0; transform: translate(-50%, -50%) scale(0.96); }
  to   { opacity: 1; transform: translate(-50%, -50%) scale(1); }
}
```

```tsx
className={cn(
  "data-[state=open]:animate-[ardulens-zoom-in_var(--ardulens-motion-base)_var(--ardulens-ease-out)]",
  "data-[state=closed]:animate-[ardulens-zoom-out_var(--ardulens-motion-fast)_var(--ardulens-ease-out)]",
)}
```

[Components/Popover](/?path=/docs/components-popover--docs), and
[Components/Drawer](/?path=/docs/components-drawer--docs) for it in use.
